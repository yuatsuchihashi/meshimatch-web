# キュレーター制度 骨子(v1)

_状態: 骨子(Kai確認用) / 2026-07-12。インセンティブ初期値「称号+先行アクセス」はKai確定済み。人選はKai実施。_

## 呼称

- 制度名: **MeshiMatch キュレーター**
- 個人の呼称: キュレーター(アプリ表示は「公式」バッジ — 実装済みの VerificationBadge)

## バッジ表示(実装済み・R5)

- プロフィール/`u/[id]`/お店カードの推薦者名に「✓公式」バッジ
- 公開おすすめリストが `/u/[id]` に表示され、フォロワーのグループ候補(Ring 2)に供給される
- 付与は運営の手動(official_verification_grants への登録)。剥奪も同経路

## 先行アクセスの中身(初期)

1. 新機能の先行利用(例: 質保証エンジンの group_fit タグ表示、D2新デザイン)
2. 恵比寿パイロットの結果・エンジン評価への意見権(ラベル検証への参加)
3. プロダクトロードマップの先行共有(月1の軽いノート)

※食事補助・収益シェアは段階2以降のKai判断事項(現段階では約束しない)

## 行動規範(規約に載せる最小セット)

1. **自分が実際に行った店だけ**を公開リストに載せる
2. **PR・提供案件は必ずPRラベルを付ける**(付け忘れはバッジ剥奪対象。システム側でも非認証者のPRはサーバー強制でfalse化済み)
3. **店舗関係者による自店の推薦は禁止**(自己登録禁止の原則)
4. 評価軸はサービスと同じ: 「外れないか」「グループで使えるか」。味の批評家である必要はない

## 運用フロー(恵比寿パイロット)

1. Kaiが10人に打診(人選・打診文はKai)
2. 承諾者に運営がバッジ付与(付与記録: いつ/誰が/根拠 — R1のグラント表)
3. 各自が恵比寿の推薦店を公開リストに登録(Google Mapsリンク貼付で自動補完 — gmaps-import)
4. 推薦データがエンジン検証(R6ループ)とRing 2供給の両方に流れる
